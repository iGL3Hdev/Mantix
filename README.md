# Mantix

Gestión del mantenimiento industrial: equipos, incidencias y órdenes de trabajo, con su historial y las reglas de estado.

## Estructura

| Carpeta     | Contenido                                                   |
| ----------- | ----------------------------------------------------------- |
| `frontend/` | Aplicación web: React, TanStack Start, Vite y Tailwind CSS  |
| `backend/`  | API REST: Spring Boot, JPA, Flyway y MySQL                  |
| `docs/`     | Guía, plan de trabajo, decisiones y especificaciones        |

## Para empezar

- **Backend:** [`backend/README.md`](backend/README.md) (MySQL en Docker y `mvnw spring-boot:run`).
- **Frontend:** [`frontend/README.md`](frontend/README.md) (`npm install` y `npm run dev`).
